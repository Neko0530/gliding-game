# Gliding Game: Wingsuit

A realistic 2D side-view wingsuit game about precision flight: leave a cliff, manage speed, angle and wind, fly through checkpoint gates, and land in a marked zone. There are no boosts. Gravity is always winning, and forward travel only comes from gliding downward.

The repository holds two versions of the same game:

| Folder | What it is |
|---|---|
| `wingsuit/web/` | Browser prototype (single HTML file, canvas). Holds the reference flight model. |
| `wingsuit-ue/` | Unreal Engine 5.8 C++ project: the same flight model ported to C++ with 3D graphics, a posed pilot, audio and a scrolling backdrop. |

## How it plays

- **Flight model:** gravity, lift, drag and momentum, with stall when the angle of attack gets too high. Posture changes speed, stability and range.
- **Wind:** a headwind with gusts, rising air (updrafts) over ridges, and a turbulence zone.
- **Course:** about 2,950 m from the cliff to the landing zone, with four checkpoint gates, trees and rock spires to avoid.
- **Landing:** outcomes are perfect, clean, rough or crash, judged on sink rate, ground speed and body angle against the slope.
- **Scoring:** distance, checkpoints, close passes, time, smooth control (overcorrections and stall time), landing quality and touchdown accuracy, graded S to D. Crashing gives a reduced score.
- **Difficulty:** Easy, Normal, Hard and Expert change landing-zone size, wind and turbulence, gate size, landing tolerance and how much of the HUD is shown. Easy shows hints.
- **Modes:** scored mission, or free flight with no score.

## Controls

| Key | Action |
|---|---|
| Space | Jump from the cliff; in flight, stabilise (wider wings, steadier) |
| W / S | Pitch up / down |
| A / D | Fine trim (lean back / forward) |
| Shift | Tuck: faster, less stable |
| Ctrl or F | Flare for landing |
| 1-4 | Choose difficulty (before jumping, Unreal version) |
| Tab | Toggle free flight (before jumping, Unreal version) |
| R | Restart |
| Esc | Pause |
| M | Mute (web version) |

Mouse movement looks ahead a little.

## Run the web prototype

Serve the folder with any static file server, for example:

```bash
python -m http.server 8765 --directory wingsuit/web
```

Then open `http://localhost:8765`.

## Build the Unreal project

Requirements:

- Unreal Engine 5.8
- Visual Studio with the "Game development with C++" workload (MSVC and the Windows SDK)

From `wingsuit-ue/`:

1. Run `build.bat` to compile the editor target.
2. Open `Wingsuit.uproject` to edit, or run the game directly:
   `UnrealEditor.exe Wingsuit.uproject -game -windowed`
3. Run `package.bat` to cook a standalone Windows build into `Dist/`. Packaging needs a lot of memory; if it fails with a paging-file error, close other heavy programs first.

The generated assets (materials, textures, audio, map) are already committed under `Content/`, so you do not need to run anything else to play.

### Tools

`wingsuit-ue/Tools/` regenerates assets if you want to change them:

- `paint_bg.py` paints the seamless illustrated backdrop into `Import/background_fallback.png` (plain Python, no dependencies). To use your own artwork, save it as `Import/background.png` instead.
- `make_audio.py` synthesises the music loop, wind loop and sound effects into `Import/Audio/` (plain Python).
- `make_level.py` runs inside the editor (`UnrealEditor-Cmd.exe Wingsuit.uproject -ExecutePythonScript=...`) and creates the materials, imports the textures and audio, and builds the level. Its rock-texture step expects the PBRgen granite set in `Import/rock/`, which is not in the repository.

## Project layout (Unreal)

| Path | Purpose |
|---|---|
| `Source/Wingsuit/WingsuitPawn.*` | Flight physics, input, scoring, camera, audio triggers |
| `Source/Wingsuit/WingsuitFlyer.*`, `WsPoseable.h` | Poses the mannequin skeleton into a wingsuit position and builds the wing fabric |
| `Source/Wingsuit/WingsuitWorld.*` | Course data: terrain height, wind, trees, spires |
| `Source/Wingsuit/WingsuitTerrain.*` | Terrain mesh, trees, boulders and bushes |
| `Source/Wingsuit/WsBackdrop.*` | Scrolling illustrated backdrop |
| `Source/Wingsuit/WingsuitHUD.*`, `WingsuitGameMode.*` | HUD, lighting and scene setup |

## Known limitations

- It is a 2D side view, so crosswind is not simulated.
- Camera zoom is fixed so the pilot stays one size; from high up you mostly see sky until the ground comes into view.
- Gates, the landing zone and the trail are drawn with debug lines, which only appear in Development builds.
- The landing feel has been tuned with scripted test flights, not with extended hand play.
